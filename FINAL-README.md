# PF-Serfer - Финальный релиз

## 🎯 Основные возможности

### ✅ Реализованные функции:
- **Человекоподобное поведение** - реалистичные движения курсора, скролл, паузы
- **Автоматическое решение капчи** - интеграция с BotLab API
- **Закрытие баннеров** - автоматическое обнаружение и закрытие модальных окон
- **Поиск на Яндексе** - полный цикл поиска с извлечением ссылок
- **Блокировка ресурсов** - настраиваемые правила блокировки
- **Управление профилями** - создание и управление браузерными профилями
- **Спуфинг** - эмуляция различных устройств и характеристик

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Создание профилей
```bash
node create-multiple-profiles.js
```

### 3. Запуск PF-Serfer
```bash
node pf-serfer.js <имя_профиля> [опции]
```

## 📋 Примеры использования

### Базовый запуск
```bash
node pf-serfer.js bot-479951176
```

### С настройками блокировки
```bash
node pf-serfer.js bot-479951176 --yandex-rules
```

### С прокси
```bash
node pf-serfer.js bot-479951176 --proxy
```

## 🔍 Поиск на Яндексе

### Использование в коде:
```javascript
import { PFSerfer } from './pf-serfer.js';

const serfer = new PFSerfer('bot-479951176', {
  blockRulesFile: 'configs/yandex-block.txt',
  allowRulesFile: 'configs/yandex-block-razreshit.txt'
});

const browser = await serfer.start();

// Переход на Яндекс
await browser.navigateToPage('https://yandex.ru');

// Поиск
const searchResult = await browser.searchOnYandex('как оформить отказное письмо');

// Получение ссылок
const links = await browser.getSearchResults();
console.log('Найдено ссылок:', links.length);
```

## ⚙️ Конфигурация

### Файлы блокировки ресурсов:
- `configs/block-rules.txt` - общие правила блокировки
- `configs/allow-rules.txt` - правила разрешения
- `configs/yandex-block.txt` - специальные правила для Яндекса
- `configs/yandex-block-razreshit.txt` - правила разрешения для Яндекса

### Настройки капчи:
- BotLab API ключ в `utils/telegram-config.js`
- Автоматическое решение SmartCaptcha

## 🎭 Человекоподобное поведение

### Реализованные алгоритмы:
- **RealisticCursor** - плавные движения курсора с естественными отклонениями
- **RealisticScroll** - имитация человеческого скролла с ускорением/замедлением
- **BannerHandler** - умное закрытие баннеров и модальных окон
- **CaptchaSolver** - автоматическое решение капчи

### Для Яндекса:
- Минимальные движения курсора на главной странице
- Плавный подвод курсора к полю поиска
- Проверка капчи и баннеров на всех этапах
- Фильтрация результатов (исключение внутренних ссылок Яндекса)

## 📊 Статистика и мониторинг

Система ведет статистику:
- Количество посещенных страниц
- Количество закрытых баннеров
- Количество решенных капч
- Время выполнения операций
